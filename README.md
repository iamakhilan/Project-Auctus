## 🎮 What Is Auctus?

Auctus is a browser-based **gamified productivity RPG** that transforms your real-world work into an exciting journey of quests, XP, streaks, rewards, and epic progression—all without leaving your browser.

> 💡 **Imagine if your to-do list felt like leveling up in your favorite game...**

### Core Philosophy
Instead of boring task lists, Auctus turns productivity into a compelling adventure where:
- **Tasks become quests** with difficulty levels and rewards
- **Focus sessions turn into boss battles** requiring strategy and skill
- **Streaks forge your legend** as you build an unbreakable chain of productivity
- **Achievements unlock** as you master different aspects of work and life
- **Your Citadel grows** with every completed challenge, representing your mastery

## 📊 Data Flow & Architecture

```
[User Action] 
        ↓
[GameStateContext] ← Single source of truth (React Context API)
        ↓
[StorageService] ← localStorage + BroadcastChannel persistence layer
        ↓
[Browser Storage] ← auctus_duo_* namespace (versioned v2.0 with schema validation)
        ↓
[Sync Events] ← Multi-tab coordination via BroadcastChannel (message passing)
        ↓
[Persistence Events] ← Error handling, fallback mechanisms, and conflict resolution
        ↓
[UI Updates] ← React re-renders with latest state (selective rendering via memoization)
        ↓
[Persistence Triggers] ← useEffect hooks debounced for performance optimization
```

### Core Architectural Principles
1. **Single Source of Truth**: All state flows through `GameStateContext` with immutable updates
2. **Immutable Updates**: State changes create new objects (no direct mutations, enabling time-travel debugging)
3. **Automatic Persistence**: Every meaningful state change triggers storage sync (debounced for performance)
4. **Multi-Tab Coordination**: BroadcastChannel keeps all tabs in sync with nonce-based deduping
5. **Error Resilience**: Storage failures show user-friendly toast notifications and automatic recovery
6. **Schema Validation**: Import/export includes version checking, migration paths, and data validation
7. **Performance Optimizations**: 
   - Memoized selectors and expensive computations
   - Virtualized lists for large data sets
   - Request animation frame alignment for animations
   - Web Workers for heavy computations when needed

## 🐞 Troubleshooting

### Common Issues & Solutions

| Issue | Solution | Prevention |
|-------|----------|------------|
| **📋 Clipboard blocked during export** | Export falls back to file download (`auctus-backup-YYYY-MM-DD.json`) with clear instructions | Click the prominent download link that appears in the notification toast |
| **💾 Storage quota exceeded** | `saveToStorage` returns `false` and shows non-blocking toast; previous save preserved; offers cleanup suggestions | Regularly export backups (Settings → Backup) to free space; enable auto-backup reminders |
| **🚫 Import rejected due to validation failure** | Malformed JSON or failed schema shows inline error with specific field issues; existing save completely untouched | Always export before importing experimental saves; use the built-in validator tool |
| **🔄 Multi-tab sync conflicts** | Delete events use BroadcastChannel with localStorage fallback, timestamp deduping, and conflict resolution strategies | Allow brief moments between tab actions; the system handles most conflicts automatically |
| **🔇 Audio not playing in Focus Arena** | Browser autoplay policies require user interaction first; clear instructions appear with a "Tap to Enable Audio" button | Click anywhere in the Focus Arena to initialize audio context; subsequent sessions work automatically |
| **🧪 Tests failing in CI but not locally** | Ensure test environment has proper `localStorage` polyfill (jsdom) and BroadcastChannel mock | Check that `src/test-setup.ts` is properly imported in vitest.config.ts; run locally with same node version |
| **⚡ Performance degradation over time** | Automatic cleanup routines prevent memory leaks; manual "Clear Cache" option in developer settings | Periodically check storage usage in Settings → Advanced; the system self-maintains |
| **🎨 Visual glitches or misalignments** | Hard refresh (Ctrl+Shift+R) clears stale CSS/JS; check for extension conflicts | Keep dependencies updated; report persistent issues with browser/OS details |

### Debugging & Development Tools
- Press `F12` or `Ctrl+Shift+I` to open Developer Tools
- Check `Application > Local Storage` for `auctus_duo_*` keys and their structure
- Look for `auctus:persistence-error`, `auctus:sync-event`, and `auctus:state-update` events in the Console
- Use `window.AUCTUS_DEBUG = true` in console for verbose logging to localStorage
- Enable "Paint Flashing" in DevTools to identify unnecessary re-renders
- Use React DevTools for component hierarchy and props/state inspection
- Check the Network tab for asset loading performance and cache hit ratios

### Recovery Procedures
1. **Soft Reset**: `Settings → Advanced → Reset UI State` (resets window size, sidebar state, etc.)
2. **Data Reset**: `Settings → Danger Zone → Reset All Data` (with confirmation and backup option)
3. **Nuclear Option**: Clear browser storage for localhost/domain and fresh start
4. **Backup Restoration**: Import previously exported JSON file with integrity verification
